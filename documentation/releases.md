# Releases

Stable and beta builds are published through GitHub Releases for Windows, Linux, and macOS.

[Download the latest stable release](https://github.com/JediofFreedom/JoF_EJK/releases/latest){ .md-button .md-button--primary }
[Browse every release](https://github.com/JediofFreedom/JoF_EJK/releases){ .md-button }

## Release channels

| Channel | Branch | Intended use |
| --- | --- | --- |
| Stable | `master` | Recommended for normal play. |
| Beta | `beta` | Prerelease testing of changes headed toward stable. |

Beta builds may change more frequently and can introduce regressions. Include the complete `/modversion` output in beta feedback.

## Release history in the repository

Older package notes live under [`ReleaseReadmes/`](https://github.com/JediofFreedom/JoF_EJK/tree/master/ReleaseReadmes). Current release pages contain the authoritative download assets and generated change lists.

## Integrity and provenance

Download client archives from this repository's Releases page. Builds are produced by the repository workflow from a recorded commit; each release page links its tag, changes, contributors, and downloadable platform archives.
